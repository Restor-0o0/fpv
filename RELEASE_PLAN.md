## Фаза 0 — блокеры релиза (сначала это)

### 0.1 Сессия пилота не закрывается при выходе/смерти/смене мира

Нет ни одного обработчика `PlayerLoggedOutEvent`, `PlayerRespawnEvent`,
`PlayerChangedDimensionEvent`. При удалённом управлении игроку ставится
`setInvisible(true)` + `setInvulnerable(true)` + `setCamera(drone)`, а снимается
это только в `endRemoteControl()`, который дёргается из тика дрона.

Ломается, если:
- игрок вышел из игры прямо в полёте — состояние уже сохранено в файл, при входе
  он невидимый и неуязвимый;
- чанк с дроном выгрузился — дрон не тикает, снимать состояние некому;
- игрок сменил измерение / умер / его телепортировали.

**Что делать:** отдельный `PilotSessionManager` (серверный), который держит
`Map<UUID, сессия>` и принудительно закрывает её на logout / respawn /
changeDimension / `EntityLeaveLevelEvent` дрона. Плюс «санитар» на входе игрока:
если в NBT висит флаг сессии, а дрона нет — снять невидимость/неуязвимость и
вернуть камеру.

### 0.2 Управление не читается с экрана

Подтверждено по коду: в подсказках HUD (`FPVOverlay.renderKeyHints`) **нет**
`PLANE_ORBIT` (G) и `FIRE_PAYLOAD` (X). Кроме того, `G` без захваченной точки
вызывает `stopPlaneOrbit()` — то есть визуально «ничего не происходит».

**Что делать:**
- добавить G в подсказки самолёта, X — в подсказки дрона;
- при `G` без цели показывать сообщение «нет захваченной точки, ЛКМ — захват»;
- вывести на HUD строку `ORBIT: ON/OFF` и радиус, когда автопилот активен;
- при захвате точки по ЛКМ давать маркер/звук, чтобы было видно, что захват был.

### 0.3 Привязка к пульту почти не находится вслепую

Механика (`RcBindingHandler`, `AttackEntityEvent`) рабочая, но:
- бьёт только `getMainHandItem()` — пульт во второй руке не привязывает;
- дальность удара по сущности в ваниле ~3 блока, до дрона надо подойти вплотную;
- нет постоянного индикатора привязки, только всплывающее сообщение и тултип.

**Что делать:**
- учитывать обе руки;
- добавить привязку на Shift+ПКМ по лучу (дальше 3 блоков);
- писать имя привязанного борта в название стака (`Пульт → Racing Drone`),
  чтобы это было видно в хотбаре;
- звук + партикл на привязку/отвязку.

### 0.4 Полный аудит всех кнопок

Текущая раскладка (`ModKeyBindings`):

| Клавиша | Действие | Где работает |
|---|---|---|
| R | смена режима полёта | дрон |

| PgUp / PgDn | наклон камеры | дрон |

| ЛКМ по борту | привязка пульта | с пультом в руке |

## Фаза 1 — «ощущение готового мода»

### 1.1 Звук (самый заметный пробел)

Своих звуков нет вообще: нет `assets/fpv/sounds.json`, нет `sounds/`. Мотор
дрона сейчас — ванильный `BEE_LOOP_AGGRESSIVE`, взрыв — `GENERIC_EXPLODE`.
Для FPV-мода это ключевая часть подачи.

Минимальный набор `.ogg`:
- луп мотора, питч и громкость от газа (отдельно для 5", whoop, гекса);
- обдув пропеллеров у земли;
- бип арминга / дисарминга, бип низкой батареи;
- шум/треск VTX при низком RSSI (уже есть модель радиолинка — привязать);
- писк детектора дронов, гул глушилки;
- свист падающего ударника, подрыв БЧ (разные по типу БЧ).

### 1.2 Метаданные мода

`gradle.properties`: `mod_name=fpv`, `mod_authors=` пусто, `mod_description=` пусто,
логотипа нет, ссылок нет. В списке модов это выглядит как заготовка.

Задать: `displayName`, описание, `authors`, `logoFile` (иконка 128×128),
`displayURL` / `issueTrackerURL` в `neoforge.mods.toml`.

### 1.3 Теги

Тегов в `data/` нет вообще. Нужны:
- `minecraft:mineable/pickaxe` + уровень инструмента на 11 блоков (сейчас всё
  ломается рукой и медленно);
- `fpv:drones` / `fpv:aircraft` — чтобы детектор, глушилка, перехватчики и
  сторонние моды целились по тегу, а не по `instanceof`;
- `fpv:warheads`, `fpv:frames`, `fpv:batteries` — для рецептов и совместимости.

### 1.4 Обучение игрока

Есть 5 advancement-веток (`root`, `beginner`, `racing`, `combat`, `utility`) —
это уже каркас онбординга. Достроить:
- цепочку «верстак → рама → сборка → первый полёт → гонка → БЧ»;
- в описаниях advancement писать нужные клавиши;
- предмет-инструкция (книга) либо страница рецептов станции сборки — сейчас
  сборка модульного дрона нигде не показана, её невозможно узнать без вики.

### 1.5 `pack.mcmeta`

`pack_format: 34` — это формат ресурсов 1.21.1; формат датапака 1.21.1 — 48.
Объявить оба через `supported_formats` / раздельные секции.

## Фаза 2 — баланс и заморозка контента

- **Проход по 77 рецептам**: выстроить кривую прогрессии
  дерево → верстак, железо → рама/моторы, редстоун+золото → пульт,
  эндер/незерит → дальнобойный пульт и тяжёлые БЧ. Сейчас рецепты корректны,
  но как единая кривая не проверены.
- **Полный survival-прогон без креатива**: собрать дрон, зарядить на станции,
  слетать гонку, собрать камикадзе, сбить его перехватчиком. Всё, что нельзя
  пройти, — правится здесь.
- **Баланс БЧ и взрывов**: 6 типов БЧ + конфиг `explosionPower`,
  `explosionBlockBreakPercent` и т. д. Зафиксировать дефолты так, чтобы
  на обычном сервере это не сносило постройки случайно.
- **Батарея как ресурс**: расход/зарядка — единственный ограничитель полётов.
  Проверить, что цикл «полетал → сел заряжать» ощущается, а не раздражает.
- После этой фазы — **content freeze**: новых дронов, самолётов и блоков в 1.0 нет.

## Что сделано в этом проходе (2026-09-07)

**Фаза 0**
- `entity/PilotSessions.java` — серверный менеджер сессий пилота: закрывает сессию
  на logout / смерть / respawn / смену измерения / выгрузку борта, плюс «санитар»
  на входе игрока по флагу `fpv_pilot_session` в persistent NBT. Телепорт назад
  теперь только если игрок в том же измерении, что и борт.
- HUD: `X` добавлен в подсказки дрона, `G` — в подсказки самолёта, плюс строки
  «ЛКМ — захват цели» и «Shift — выход». На OSD самолёта строка `TRK: FREE/LOCK/ORBIT`.
- `G` без захваченной точки больше не молчит — сообщение; захват/сброс по ЛКМ и
  вкл/выкл орбиты дают сообщения в action bar.
- Пульт: привязка с обеих рук, Shift+ПКМ по лучу на всю дальность пульта,
  имя привязанного борта в названии стака, звук + партиклы на привязку.

**Фаза 1**
- `sound/ModSounds.java` + `assets/fpv/sounds.json` — 17 событий как алиасы
  на 17 собственных моно `.ogg` в `assets/fpv/sounds/`, синтезированных
  процедурно (numpy + soundfile/libsndfile). Весь код мода ходит через
  `ModSounds.*`, так что заменить любой файл можно без правок кода.
- `client/sound/DroneMotorSound` — зацикленный звук моторов, следует за бортом,
  громкость и питч от скорости; вешается на любой дрон/самолёт при появлении.
- Метаданные: `FPV Drones`, автор, описание, версия `1.0.0`, логотип
  `fpv_logo.png` 256×256.
- Теги: `mineable/pickaxe` и `needs_stone_tool` на блоки (металлические станции
  теперь требуют кирку), `fpv:drones|planes|aircraft|hostile_drones` для сущностей,
  `fpv:drones|planes|warheads|frames|batteries|motors|...|components` для предметов.
- Advancement: `radio` → `first_flight`, плюс `fixed_wing`, `logistics`, `defence`.
- Подсказки-однострочники на всех 11 блоках (`BlockHintTooltips`).
